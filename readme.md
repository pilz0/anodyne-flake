# anodyne-flake
This is a flake for the deployment of https://anodyne.wiki.

## Services
### chrp
This is a service for scraping sources and setting up the static content (icons, ...)
Provides the oneshot services `anodyne-chrp-init` (initial setup) and `anodyne-chrp` (scrapes substance data).
#### options
```nix
anodyne-wiki.chrp = {
    enable = bool;
    cacheDir = path; # Scraper cache directory. Defaults to `/tmp/chrp`.
    databasePath = string; # sqlite database chrp writes to. Defaults to `/var/lib/anodyne/db.sqlite`, keep it in sync with `api.databasePath`.
};
```

### api
The API has a sqlite with the generated data from chrp and serves that.
Runs as the `anodyne-api` service and is reverse proxied by caddy under `/api/*`.
#### options
```nix
anodyne-wiki.api = {
    enable = bool;
    databasePath = string; # sqlite database generated by chrp. Defaults to `/var/lib/anodyne/db.sqlite`.
    port = int; # Defaults to 8080.
    pageHookFile = path; # Environment file containing `PAGE_HOOK=<url>`, the Discord webhook url for substance page requests. Page requests are not forwarded when unset.
};
```
### frontend
The static frontend files served by caddy, built from anodyne-frontend.
When chrp is enabled, the `anodyne-frontend-sync` service copies the package to `/var/lib/anodyne/frontend` so chrp can write its generated files (structures, icons, ...) next to it. Files from the package are overwritten on every update, generated files are kept.
#### options
```nix
anodyne-wiki.frontend = {
    package = package;
    root = string; # Directory the frontend is served from. chrp writes its results into the frontend, so a writable copy of the package is used when chrp is enabled.
};
```
### caddy
Serves the frontend and reverse proxies `/api/*` to the API, with automatic https.
#### options
```nix
anodyne-wiki.caddy = {
    enable = bool;
    domain = string; # Domain the wiki is served on.
    contactEmail = string; # ACME contact email.
    serverName = string; # Defaults to `anodyne_wiki`.
    adminPort = int; # Caddy admin API port on localhost. Defaults to 2019.
    apiPort = int; # Port the API listens on. Defaults to 8080, keep it in sync with `api.port`.
};
```

## pkgs
Installs the anodyne tools into the system packages (`anodyne-wiki.pkgs.enable = true;`):
* anodyne-api
* anodyne-chrp
* anodyne-molpic

## Example setup
Add this to your flake.nix
```nix
inputs.anodyne-flake.url = "github:pilz0/anodyne-flake";
```
* Add this to your host config
this also set up automatic https
```nix
anodyne-wiki = {
    enable = true;
    api.enable = true;
    chrp.enable = true;
    pkgs.enable = true;
    caddy = {
        enable = true;
        domain = "anodyne-nix.as214958.net";
        contactEmail = "acme@pilz.foo";
    };
};
```
* run these services in tmux 
once for setup (sets up icons etc)
```bash
systemctl start anodyne-chrp-init
```
after adding new substances to anodyne-frontend (and once to pull all substance data)
```bash
systemctl start anodyne-chrp
```
